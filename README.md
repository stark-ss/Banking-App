# Secure Full-Stack Bank Management Application
A modern digital banking web application featuring secure user authentication ,real-time account tracking and financial transaction management.

## TECH STACK
* **Frontend:** HTML, JavaScript, CSS, React, Tailwind CSS,Vite
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Security:** JSON Web Token(JWT), bcrypt for password hashing

# CORE FEATURES
* secure user registration and login with input validation
* live dashboard displaying account status, account numbers and balances
* Instant deposit, withdrawal and account-to-account maintaining ACID properties of transactions
* detailed transaction history logging with precise timestamps and color coding for type of transactions
